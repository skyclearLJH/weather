# KBS 레이더 방송 원고 생성기

## 목표

기상청 레이더 실황, 초단기 강수예측, AWS 매분 관측을 바탕으로 TTS 1.1배속 재생 시 약 1분 분량의 한국어 방송 원고를 생성한다. 결과는 TTS와 영상 생성에 바로 사용할 수 있도록 짧은 행 단위와 단락 간 빈 줄을 유지하며, 마지막에 `//`를 붙인다.

## 데이터 기준

- 레이더 HSP 합성 강수 격자에서 육지의 시간당 10mm 이상 에코만 주요 현황으로 다룬다.
- 고정 도시 목록만 확인하지 않는다. 전국 격자에서 강수 핵을 먼저 탐지하고 행정구역 및 인근 관측 지점과 매칭한다.
- 해상 에코는 현재 상황 설명에서 제외한다. 기상청 초단기예측에서 육지 유입 가능성이 확인될 때만 언급한다.
- 강수 핵 주변 AWS 매분 자료의 `RN-60m`를 함께 조회한다. 가까운 지점의 실제 1시간 강수량을 자연어로 제공한다.
- `RN-60m`가 10밀리미터 이하인 관측 지점은 기사 분석과 원고 생성에서 모두 제외한다. 10밀리미터를 초과한 지점만 사용한다.
- 동영상의 1시간 강수량 순위표와 원고 생성 시각이 다를 수 있으므로 원고에는 소수점이나 정확한 `RN-60m` 값을 쓰지 않는다. `51.8밀리미터`는 `50밀리미터가 넘는`, 경계값은 `50밀리미터에 가까운` 또는 `50밀리미터 안팎의`처럼 10밀리미터 단위로 근사한다.
- 여러 관측 지점을 묶을 때도 개별 값을 나열하지 않고 공통 강도대를 `30밀리미터가 넘는`, `40밀리미터 안팎의`처럼 표현한다.
- 비슷한 강도의 관측 지점은 `화성 운평, 가평 외서, 포천 영중에서는 지난 1시간 동안 모두 30밀리미터가 넘는 비가 관측됐습니다`처럼 한 문장으로 묶는다. 지점별 값을 문장 하나씩 나열하지 않는다.
- 레이더에서 시간당 30밀리미터 이상으로 추정되고, 같은 강수 핵 주변의 지상 관측에서도 지난 1시간 강수량이 10밀리미터를 초과한 지역을 상세 설명 대상으로 우선 선정한다.
- 레이더·지상 관측 일치 지역이 하나라도 있으면 레이더만 강한 다른 지역은 원고에서 제외한다. 일치 지역이 하나면 해당 권역에 집중하고, 여러 곳이면 일치한 지역을 모두 다룬다.
- 관측 지점은 `AWS`라는 기술 용어 대신 `가까운 정읍 내장산 지점`처럼 지역명과 지점명을 함께 표기한다.
- 레이더 위치 변환은 화면 렌더링과 같은 좌표 방향을 사용한다. 레이더 격자의 남북 축을 반대로 적용하지 않는다.
- 레이더, AWS, 초단기예측 요청은 병렬로 수행하고 AWS 자료는 1~3분 캐시해 응답 지연을 줄인다.
- 비구름의 이동 방향과 강수 구역 확대·축소는 산출하지 않는다. 현재 강수 핵이 놓인 동일 격자의 10여 분 전 강도와 현재 강도는 직접 비교하고, 단계가 달라질 만큼 뚜렷할 때만 `강해졌다` 또는 `약해졌다`고 쓴다.

## 초단기예측 원칙

- 원고에는 앞으로 약 1시간까지만 반영한다.
- 미래 표현은 반드시 다음 취지의 단서를 포함한다: `레이더 영상을 바탕으로 기상청이 예측한 초단기 예측에서는`.
- 관측 사실과 예측을 같은 문단에 섞지 않는다.
- 예측은 `가능성이 있습니다`, `예상됩니다`처럼 조건부로 쓴다. 확정적 표현은 사용하지 않는다.
- 비슷한 예측 강도와 인접 지역은 한 문장으로 묶고, 지역마다 예측값을 따로 낭독하지 않는다.
- 초단기예측도 현재의 레이더·지상 관측 일치 지역과 지명 또는 위치가 이어지는 강수 핵만 원고에 반영한다.
- 같은 예측 지역의 초반과 후반 강도가 뚜렷하게 달라질 때만 `점차 강해질`, `점차 약해질` 경향을 덧붙인다. 이를 이동 방향이나 강수 구역 확대·축소로 해석하지 않는다.
- 예측 자료가 오래됐거나 불완전하면 미래 전망을 생략한다.

## 원고 구성

1. "레이더 영상을 통해 현재 비구름 상황과 앞으로 한 시간 전망을 함께 살펴보겠습니다."
2. 현재 시각과 육지의 시간당 10mm 이상 강수대의 전국 분포를 짧게 설명한다.
3. 가장 강한 육지 강수 핵의 위치와 레이더상 추정 강도를 설명한다.
4. 같은 위치에서 확인된 10여 분 전 대비 강도 변화가 있으면 이동·확대로 해석하지 않고 설명한다.
5. 인근 실제 관측 지점의 지난 1시간 강수량을 비슷한 값끼리 묶어 설명한다.
6. 필요하면 두 번째 강수 핵을 추가하고, 수치를 반복하지 않는 상황 해설과 주의 문장을 잇는다.
7. 기상청 초단기예측에 따른 향후 1시간 가능성을 비슷한 지역끼리 묶어 별도 문단으로 제시한다.
8. "해당 지역에서는 최신 기상 정보와 특보 상황을 계속 확인하시기 바랍니다."로 마무리한다.

## 문체 규칙

- 목표 길이는 공백 제외 351자 안팎이다. 이는 공백 제외 456자를 TTS 1.1배속으로 재생했을 때 78초가 걸린 실측을 바탕으로, 최종 영상이 약 60초가 되도록 환산한 값이다.
- 방송용 쉬운 한국어를 쓴다. API, AWS, 격자, 추정 오차 등 기술 설명은 원고에 넣지 않는다.
- 인접 문장에서 같은 종결어미와 핵심 수식어를 반복하지 않는다. 예: `발달해 있습니다`, `강한`, `매우`, `계속`의 연속 사용을 피한다.
- 숫자는 판단을 뒷받침하는 근거로만 쓰고, 현재 분포·강도 변화·지역별 차이·주의점이 이어지는 기사 문장으로 구성한다.
- 지역명, 강수 강도, 관측값을 정확히 구분하고 과장하지 않는다.
- 레이더 추정치는 `레이더에서는 ... 추정되는 비구름`처럼 표현하고, 실제 강수량은 `지난 1시간 동안 ... 비가 관측됐습니다`로 표현한다.
- 시청자에게 레이더 확인을 권하지 않는다. 마지막 안내는 최신 기상 정보와 특보 상황으로 한정한다.

## 구현 범위

- 기존 레이더 방송 모드의 데이터 모듈을 재사용한다.
- 별도 API 또는 Cloudflare Function에서 분석 결과를 구조화된 JSON으로 만든다.
- JSON에는 관측 시각, 육지 강수 핵 목록, 인근 관측값, 초단기예측 요약, 원고 생성용 사실 목록을 포함한다.
- 원고 생성 모델에는 관측 사실과 편집 규칙만 전달하고, 모델이 수치나 지명을 임의로 보완하지 못하게 한다.
